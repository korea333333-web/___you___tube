## 검증본의 보완 내용

- 기존 labs.google 경로와 flow.google.com 호스트 처리. 한국어 새 프로젝트 버튼과 계정 표시 대응. 공개 페이지의 계정 아이콘만으로 workspace 판정하지 않음.
- 연결 실패 시 전용 MCP 내부에서 로컬 스크린샷과 구조 진단 JSON 저장. UI 인식 실패와 계정 선택 미완료를 구분.
- 생성 중 오류에도 원래 Job ID와 상태 반환. 제출 이후 불확실한 오류는 needs_attention으로 기록하고 재제출하지 않음.
- 전체 UUID 파일 이름. 같은 바이트 재다운로드는 허용, 다른 기존 파일 덮어쓰기와 빈 파일은 차단.
- 페이지 본문에 있는 영상 길이를 선택 가능한 길이로 오인하지 않음. 실제 길이 탭이 있으면 선택 후 요청.
- 지정한 프로젝트를 찾지 못하면 임의의 다른 프로젝트로 넘어가지 않음.

## 검증 방법과 한계

원본 0.2.3 / 6826452a4a2e93bf7313d1be1626a9034fd7dc27의 기본 테스트 33개 통과. 검증본은 기존 테스트와 6개 회귀 테스트를 추가했습니다. DOM 테스트는 웨일에서 about:blank의 로컬 HTML만 사용하며, Google에 접속하거나 생성하지 않습니다. 최신 전체 결과는 test-results.txt에 기록합니다.

계정 연결이 성공해야 실제 모델·비율·길이·개수 정보를 확인할 수 있습니다. 그 다음 가장 중요한 장면 1개에 대해 실제 조건을 보여주고 승인받아야 생성·다운로드까지 검증할 수 있습니다. 승인되지 않은 영상 주제나 대본은 만들어 승인 처리하지 않습니다.

음악, 자막, 음성 합성, 최종 편집, DaVinci Resolve, 업로드는 대상이 아닙니다. 현재 구현은 Codex가 승인 단계를 관리하는 문서·도구 워크플로이며 별도 무인 영상 제작 서비스는 아닙니다.

## 최신 사용자 저장 방식
