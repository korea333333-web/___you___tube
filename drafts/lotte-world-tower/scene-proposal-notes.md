# 롯데월드타워 장면·Omni 프롬프트 제안
작성일: 2026-09-10. 상태: 후속 준비 초안, 실제 영상 생성·다운로드 없음.

## 길이와 원문
원문 내레이션 8개 그룹을 그대로 보존한다. 헤딩·타임코드·연기 지시·출처는 읽지 않는다. JSON의 narrationLineIds는 원문 행을 가리키며 한 행에 문장이 여러 개일 수 있다. 모든 행은 순서대로 정확히 한 번 연결한다.

부모 작업이 만든 audio/narration-groups.json의 Microsoft Heami Desktop, rate 0 후보는 306.634740초(약 5분 7초)다. 원래 4~5분은 미측정 추정이었으며 이 후보 음성의 사용자 승인은 별도다. 다른 목소리·속도를 쓰면 다시 측정한다. 원문을 줄이거나 임의로 재생 속도를 높이지 않는다.

34개 × 10초, 총 소스 340초다. 그룹별 배정은 3 / 4 / 5 / 3 / 4 / 5 / 4 / 6개. 그룹 실측 길이만큼 컷을 줄여 연결하면 기본 본편 약 306.635초가 된다. 별도 앞뒤 여백은 추가된다. suggestedTimeline은 각 그룹 안의 균등 임시 배치로, 단어 단위 정렬 결과가 아니다. 숏별 narration은 의미 대응이며 문장이 10초 경계에 맞춰 끝나야 한다는 뜻이 아니다. 그룹 음성은 계속 재생하고 청취 또는 정렬 후 정확한 컷을 확정한다.

## 실제 설정과 승인
부모 작업에서 실제 MCP 설정 확인: Omni 1.1 Flash (omni-1-1-flash), 16:9, 10초, 출력 1개. 이 하위 작업은 Flow에 접속하지 않았다. 사용자는 현재 대본 확정 및 Omni 1.1 Flash·10초·16:9·1출력·총 34개, 정확한 크레딧 수치 미확인이라는 조건을 안내받은 뒤 다음과 같이 명시적으로 승인했다: ‘지금 연결되어있는 구글 아이디는 영상을 쓸수있어 무료로 안해도 되는거야 그러니가 그냥 전체를 진행시켜 물어보지마’. 이 범위의 전체 진행에 별도 중간 확인을 요구하지 않는다. 크레딧 비용은 미확인이고 추정하지 않는다. 이 하위 작업 자체는 제출·Job 생성·다운로드를 실행하지 않았으며 실제 실행 상태는 부모 작업의 생성 로그가 기록한다.

첫 테스트 추천은 제안 2번 ‘질문의 대상에 가까이’. 본편 매핑은 group-01의 3~4행이지만 테스트 발췌는 같은 그룹의 2~3행이다. 부모 작업이 준비한 약 7.053초 음성에 앞뒤 여백을 두는 10초 테스트를 전제로 한다. 테스트 출력 scene-01과 제안 번호 2의 대응은 제출 담당이 기록한다. 이 작업은 제목 폴더·출력 폴더를 만들지 않았다.

## 영상 원칙
모든 영어 프롬프트에 No speech, no music을 포함한다. 한 숏 한 동작이며, 사람의 대사·입 모양을 만들지 않는다. 원본 영상 오디오는 동일 여성 음성 편집에서 제거한다. 여기서 음성 합성·편집은 실행하지 않았다. 음악·자막·필수 숫자 오버레이를 만들지 않고 수치는 내레이션으로 전달한다.

공사 화면은 AI 재현이며 실제 촬영기록으로 소개하지 않는다. 막대·매트 모형과 대표 구조 디테일은 개념·비유로 구분하며 실제 설계 단면이나 인증된 구조도라고 주장하지 않는다. 108개 파일, 6.5m, 32시간, 500m, 메가컬럼 8개는 공식 자료를 근거로 음성이 설명하고 생성 이미지의 정확한 배치로 증명하지 않는다.

완공 후 현재 전경, 기초 공사, 골조 공사, 상부 마무리 공사, 장비 해체는 하드컷으로 구분한다. 한 클립에서 건물 완성도·시대가 변하는 타임랩스나 모핑은 없다. 알아볼 수 있는 외관과 기계 작동은 실제 참고자료와 비교해야 한다. 출처 링크의 존재만으로 사진 재사용 권리나 MCP 참고 이미지 입력 지원을 확정하지 않는다.

## 결과 QA
- 외관: 실제 타워 테이퍼·첨탑·창 배열과 비교. 추가 첨탑·다른 건물 혼합·뒤틀린 유리는 폐기.
- 기초: 임의 파일 전체 배치·허구 눈금·사람 3명 쌓기 금지. 매트 모형은 단순 스튜디오 모형이다.
- 압송: 펌프와 불투명 배관 연결이 일관되어야 함. 허구 압력값·강도 시험을 추가하지 않음.
- 거푸집: 가이드·지지가 불명확하거나 플랫폼이 뜨면 폐기. 불확실하면 JSON의 정지 플랫폼+상승 카메라 대체 프롬프트 사용.
- 구조: 실제 단면·8개 기둥 배열·아웃리거 층을 임의 확정하지 않음. 대표 연결부를 실제 타워 접합 상세라고 소개하지 않음.
- 크레인: 이미 분리된 부품 하나만 한 번 운반. 줄·하중 연결이 일관되고 사람이 하중 아래에 있지 않아야 함. 여러 크레인 연속 해체나 크기 변형 금지.
- 엘리베이터: 최종 소형 크레인을 분해한 작은 부품만 운반. 온전한 크레인·거대 붐 탑승 금지. 두 숏의 카트·부품·조명 연속성과 문 관통 여부 확인.
- 참여사: 국내 시공과 국제 설계 역할을 그대로 구분. 가짜 로고·서명·실제인 척하는 설계 문서·국기 연출 없음.

동일 크레인·카트 참고 입력 지원은 미확인이다. 지원되면 승인된 결과를 참고할 수 있고, 지원되지 않으면 형태가 맞는 결과를 골라 쓰거나 기존 숏 재사용을 검토한다. 승인된 총 34개 범위를 넘는 추가 생성이나 업스케일은 이 계획에 포함하지 않는다. 같은 Job 처리 중에는 재제출하지 않는다.
