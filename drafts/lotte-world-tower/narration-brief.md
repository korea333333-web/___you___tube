# 롯데월드타워 내레이션 방향

상태: 사용자 요청 반영 · 음성 파일 미생성 · 음성 도구와 보이스 미선정
작성일: 2026-09-10

- 한국어 표준어, 신뢰감 있는 성인 여성 아나운서 톤. 같은 목소리를 전 구간 유지.
- 차분한 다큐멘터리 설명. 명료한 발음과 자연스러운 문장 끝맺음. 과장된 광고식 감탄은 줄인다.
- 숫자·낯선 용어는 천천히. 목표 4~5분은 기획 추정이며 실제 길이는 음성으로 확인.
- 핵심 질문과 큰 숫자 뒤 약 0.4~0.7초 쉼. 실제 음성에 맞춰 조정.
- 555m=오백오십오 미터, 123층=백이십삼 층, 6.5m=육 점 오 미터, 108개=백여덟 개, 32시간=서른두 시간, KPF=케이피에프, LERA=레라.
- 시간표, 대괄호 지시, 출처 링크는 읽지 않는다.
- 현재는 전체 대본 승인 단계. 승인 후 장면 프롬프트와 음성 구현 방법을 준비한다.

내레이션은 사용자 추가 요청에 따라 범위에 포함했다. 실제 음성/영상 생성은 아직 실행하지 않았다.
