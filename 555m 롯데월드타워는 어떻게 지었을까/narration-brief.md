# 롯데월드타워 내레이션 방향

상태: 로컬 무료 음성 후보 제작 완료 · 사용자 목소리 품질 확인 전
작성일: 2026-09-10

- 한국어 표준어, 신뢰감 있는 성인 여성 아나운서 톤. 같은 목소리를 전 구간 유지.
- 차분한 다큐멘터리 설명. 명료한 발음과 자연스러운 문장 끝맺음. 과장된 광고식 감탄은 줄인다.
- 숫자·낯선 용어는 천천히. 목표 4~5분은 기획 추정이며 실제 길이는 음성으로 확인.
- 핵심 질문과 큰 숫자 뒤 약 0.4~0.7초 쉼. 실제 음성에 맞춰 조정.
- 555m=오백오십오 미터, 123층=백이십삼 층, 6.5m=육 점 오 미터, 108개=백여덟 개, 32시간=서른두 시간, KPF=케이피에프, LERA=레라.
- 시간표, 대괄호 지시, 출처 링크는 읽지 않는다.
- 현재는 전체 대본 승인 단계. 승인 후 장면 프롬프트와 음성 구현 방법을 준비한다.

내레이션은 사용자 추가 요청에 따라 범위에 포함했다. 로컬 후보 음성은 생성했으며 실제 Flow 영상/유료 음성 생성은 실행하지 않았다.

## 현재 후보

- 설치된 Microsoft Heami Desktop(한국어 여성), Rate 0.
- 전체 8개 오디오 합계 306.635초. 별도 서비스 비용 없음.
- 테스트 파일: audio/test-narration-10s.wav. 실제 발화 7.053초에 앞뒤 여유를 더해 10초.
- 최종 여성 아나운서 느낌의 적합성은 첫 테스트에서 사용자 확인.
- Flow의 내장 음성 참조는 공식 안내에 있으나 현재 MCP 선택 기능은 미검증이므로 확정된 기능으로 전제하지 않음.
