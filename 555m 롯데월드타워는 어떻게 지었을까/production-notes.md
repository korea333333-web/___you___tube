# 제작 안내

이 영상은 롯데월드타워의 건설 과정을 공개 자료로 확인해 설명하는 콘텐츠입니다. 생성 영상은 설명을 위한 AI 재구성이며 당시 공사 현장을 촬영한 기록 영상이 아닙니다. 기술 구조의 세부 형상과 작업 배치는 실제 도면의 정밀 복제라고 보장하지 않습니다.

- 자료와 사실 확인: research.md
- 전체 내레이션: script.md
- 장면·프롬프트: scenes.md, veo-prompts.md
- 실제 생성 상태와 파일: generation-queue.json, 각 scene 폴더의 job.json
- 음성: 한국어 여성 Microsoft Heami Desktop을 일관되게 사용. 생성 클립 원음은 최종 편집에서 제거하고 동일한 내레이션을 넣습니다.
- 현재 작업: 승인된 34개 클립 생성·다운로드와 여성 내레이션 편집을 완료했습니다. 완성본은 555m-롯데월드타워-완성본.mp4입니다.

완성도와 실제 생성·다운로드 여부는 최종 검증 기록으로 구분합니다.

## 완성본 확인

- 길이: 306.766667초(약 5분 7초), 1280×720, 30fps, H.264/AAC.
- 원본 34개는 각각 10초이며, 대본 순서로 필요한 구간을 잘라 8개 내레이션 그룹과 연결했습니다.
- 전체 디코딩 정상 종료, 완전한 검정 구간(0.4초 이상) 미검출, 최대 감지 휴지 1.052초, 오디오 피크 -4.55dBFS.
- 시각 검수는 각 원본의 표본 프레임과 완성본 9개 프레임에 근거합니다. 실제 모든 중간 움직임이나 사람이 전체 음성을 듣고 확인했다고 기록하지 않습니다.
- 일부 비유 모형·카트·엘리베이터 디자인이 장면 사이에 다르고, 일부 패널과 입구에 생성된 문자 무늬가 있습니다. 모두 설명용 AI 재현이며 실제 특정 현장·기업의 정확한 장비나 배치로 단정하지 않습니다.
- 상세 검증: qa/final-film-verification.json, qa/production-quality-summary.json.
